# @toolveto/core

The core engine for deterministic chaos testing, schema validation, and remediation generation for Model Context Protocol (MCP) servers.

- **License**: MIT
- **Features**:
  - D1 Idempotency burst and replay testers
  - D2 Deterministic type-inversion error handling fuzzers
  - D3-lite Context hygiene and pagination schema linters
  - Actionable copy-paste diff generator for Zod, FastMCP, and Go
