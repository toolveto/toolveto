# ToolVeto Published Corpus (40% Public Baseline)

This directory contains the public 40% base test fixtures, deterministic type-inversion vectors, and baseline idempotency burst configurations distributed under **Creative Commons Attribution 4.0 International (CC-BY 4.0)**.

## Moat Protection Architecture

The proprietary 60% adversarial test suite, dynamic cryptographic nonces, and mutating LLM steerability batteries reside exclusively in the private repository (`toolveto-cloud/packages/sealed-corpus`). This guarantees that tool authors cannot hardcode static test fixture responses to game public verification scores.
